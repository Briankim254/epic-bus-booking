# CLAUDE.md

Guide for AI coding assistants working in this repo. The full build plan is in [docs/PLAN.md](docs/PLAN.md).

## Layout

- `backend/`: FastAPI app, a uv workspace member. Python 3.14, SQLAlchemy 2.0 (sync), Alembic, PostgreSQL.
- `frontend/`: React SPA, a yarn workspace. Vite, TanStack Router and Query, shadcn/ui, and a typed client generated from OpenAPI.
- Root: `pyproject.toml` (uv workspace), `package.json` (yarn workspaces), `compose.yml`.

### Backend layers

| Layer | Rule |
|---|---|
| `api/routes/` | HTTP only. Parse the request, call one service method, shape the response. No business rules |
| `services/` | Orchestration and transaction boundaries |
| `repositories/` | All SQL lives here. Bound parameters only, never f-strings in `text()` |
| `domain/` | Pure Python. Imports nothing from FastAPI, SQLAlchemy or the rest of `app` |
| `models/` | SQLAlchemy tables. Every module must be imported in `models/__init__.py` |
| `schemas/` | Pydantic API contracts, kept separate from tables |
| `core/` | Settings, DB engine, problem+json errors, JSON logging and request IDs |

## Commands

```bash
uv sync --all-packages                         # Python deps (repo root)
yarn install                                   # JS deps (repo root)
docker compose up -d db                        # Postgres only
cd backend && uv run fastapi dev               # API on :8000
cd backend && uv run bash scripts/test.sh      # tests
cd backend && uv run bash scripts/lint.sh      # mypy strict + ruff
cd backend && uv run alembic revision --autogenerate -m "..."
yarn dev                                       # web on :5173
bash scripts/generate-client.sh                # regenerate frontend/src/client
```

## Invariants

- `trips.seats_booked` changes **only** through the conditional `UPDATE` in `repositories/trips.py`. Never read it and then write it back. The `ck_trips_seats_range` CHECK is the backstop.
- Trip status rules live only in `domain/trip_status.py`. Nothing else compares statuses.
- Money is in integer US cents.
- Every error response is `application/problem+json`. Never echo the submitted input back.
- Never log passenger names, full booking references or request bodies.
- Regenerate the frontend client in the same change as any API schema change.
- Read every autogenerated migration before keeping it. Never edit a migration that has been applied anywhere shared.
- Tests run Alembic against `app_test`. Don't use `create_all`.

## Secrets

Never read `.env` or `.env.*`; `.claude/settings.json` denies it. Use obvious dummies in examples (`postgres://app:example@db/app`).
