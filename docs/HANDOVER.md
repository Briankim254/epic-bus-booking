# Handover note

The three most important things to know before changing this code.

## 1. Seat counts change in one place

The conditional `UPDATE` in `repositories/trips.py`, backed by the `ck_trips_seats_range` CHECK. Run `python -m app.cli reconcile` if in doubt: any drift is a bug._

## 2. Business rules live in `domain/` and are pure

_Fares, the trip state machine and booking references. Routers and repositories contain no rules._

## 3. Migrations, and what is deliberately missing

_Review every autogenerated migration, and never edit one that has been applied. Admin endpoints are unauthenticated by design: `require_admin` in `api/deps.py` is where auth goes._
